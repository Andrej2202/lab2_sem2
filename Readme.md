##  Описание проекта

Лабораторная работа по курсу "Информатика (организация и поиск данных)". 

**Цель:** Разработка системы индексации записей студентов с файловым хранением и сравнение алгоритмов поиска (бинарное дерево vs отсортированная последовательность).

**Предметная область:** База данных студентов с атрибутами:
- `firstName` - Имя
- `lastName` - Фамилия  
- `birthYear` - Год рождения (ключ индексации)
- `group` - Учебная группа

**Основные возможности:**
- Индексирование данных по году рождения
- Точный поиск студентов по году
- Поиск по диапазону годов
- Хранение данных в бинарном файле
- Сравнение производительности алгоритмов поиска

---

##  Архитектура

### Структуры данных

Проект использует две альтернативные структуры для индексации:

1. **BinaryTree** (Бинарное дерево поиска)
   - Шаблонный класс `BinaryTree<Pair<int, size_t>>`
   - Итератор для симметричного (in-order) обхода
   - Эффективный поиск по диапазону

2. **SortedSequence** (Отсортированная последовательность)
   - Наследуется от абстрактного `Sequence<T>`
   - Бинарный поиск с выбором стратегии деления:
     - Классическое деление пополам
     - Золотое сечение (0.382)

### Хранение данных

- Объекты `Student` хранятся в **бинарном файле**
- Индексы хранят пары `Pair<int, size_t>`:
  - `first` - ключ (год рождения)
  - `second` - смещение записи в файле

##  Бенчмарк

### Сценарии тестирования

Бенчмарк сравнивает производительность на трёх типах данных:

1. **Sorted Ascending** - данные отсортированы по возрастанию birthYear
2. **Sorted Descending** - данные отсортированы по убыванию birthYear
3. **Random** - данные в случайном порядке

### Измеряемые метрики

- Время построения индекса (мс)
- Время поиска по диапазону [1995, 2005] (мс)

### Размеры тестовых данных

- N = 1000
- N = 10000

### Формат результатов

Файл `results.csv` содержит:

```csv
Тип_данных; N; Время_построения_Дерево; Время_построения_Массив; Время_поиска_Дерево; Время_поиска_Массив
Sorted Asc; 1000; 12.5; 8.3; 0.15; 0.08
Sorted Desc; 1000; 45.2; 8.1; 0.12; 0.07
Random; 1000; 15.8; 9.2; 0.14; 0.09
```

### Анализ результатов

**На отсортированных данных:**
- Бинарное дерево вырождается в список
- Сложность вставки: O(n²)
- Дерево работает значительно медленнее

**На случайных данных:**
- Дерево сбалансировано
- Сложность вставки: O(n log n)
- Производительность сопоставима с массивом

**Поиск по диапазону:**
- Оба метода эффективны: O(log n + k)
- Дерево может быть быстрее за счёт пропуска поддеревьев

##  Технические детали

### Формат бинарного файла

Структура записи `Student`:

```
[uint32_t firstName_length][char* firstName]
[uint32_t lastName_length][char* lastName]
[int32_t birthYear]
[uint32_t group_length][char* group]
```

### Стратегии бинарного поиска

**Классическое деление пополам:**
```cpp
mid = (left + right) / 2
```

**Золотое сечение:**
```cpp
mid = left + (right - left) * 0.382
```

### Управление памятью

- Используются **сырые указатели** (в соответствии с базовой архитектурой)
- Деструкторы корректно освобождают память
- Запрещено копирование для `BinaryTree` (избежание двойного освобождения)

### Исключения

Кастомные исключения для обработки ошибок:
- `IndexOutOfRangeException` - выход за границы индекса
- `InvalidArgumentException` - невалидный аргумент
- `EndOfStreamException` - достигнут конец потока
